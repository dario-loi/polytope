Introduction

One construction kit and one design language for every site, paper page, and demo Dario Loi ships.

What is a design system?

A design system is two things at once: a construction kit you take components from, and a design language that keeps a homepage, a paper page, and a demo reading as one person's work.

# add the core to any project
npm install github:darioloi/design-system
