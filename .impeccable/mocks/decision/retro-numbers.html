Introduction

A design system is two things at once. It is a construction kit of tokens, CSS components, and Astro wrappers, and it is a design language: the principles, color, type, and writing rules that make a homepage, a paper page, and a demo read as one person's work.

Version 0.1 is experimental. Component APIs may change before 1.0.
# add the core to any project
npm install github:darioloi/design-system
