0.1Introduction

A design system is two things at once. It is a construction kit: tokens, CSS components, and Astro wrappers you take pieces from. It is also a design language: the principles, color, type, and writing rules that make a homepage, a paper page, and a demo read as one person's work.

Definition 0.1Design token

A named design decision, such as color.series.yellow, stored once and compiled to CSS, Astro, and Python.

0.2# add the core to any project
npm install github:darioloi/design-system
